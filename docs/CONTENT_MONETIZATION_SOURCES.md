## 过滤原则

- 优先级依次为：机会、真实案例、可操作工具、平台规则。
- 命中创作者增长、内容生产、短视频/直播带货、数字产品、接单和收入案例的 OPML 条目可进入重点流。
- “零门槛暴富、一夜暴富、躺赚、保证收入”等不可核验营销词直接降噪。
- 泛模型、论文、芯片和融资新闻降低排序；官方 AI 产品更新保留为工具能力信号。
- 摘要保留原始来源链接，收入与转化数据仍需回到原文核验。

## 已验证但未采用

- YouTube 官方旧 Blogger Feed：XML 可解析，但最新条目停留在 2020 年。
- TikTok Newsroom、TikTok Business Blog：候选 RSS URL 实际返回 HTML。
- Instagram Blog、Shopify Blog、Beehiiv Blog、Patreon News：候选 URL 返回 HTML 或 404。
- Indie Hackers：公开候选 Feed 返回 HTML；第三方非官方 Feed 不采用。
- Side Hustle Nation：Feed 可解析，但最新条目停留在 2024 年。
- 数英、少数派：Feed 可用，但泛营销/消费内容比例高，暂不加入。

## 已知缺口

### 视频号

微信视频号的官方规则、直播和商品转化信息目前缺少稳定、公开、无需登录的 RSS/Atom。为避免脆弱桥接、转载失真和登录风险，本轮不接入非官方抓取。

当前只能通过“运营派”等公开 RSS 捕捉少量视频号行业信息，无法保证完整覆盖。若要加强，最小决策是指定 1–3 个认可的来源，并决定是否接受非 RSS 网页监控或邮件订阅、是否允许其内容进入公开 Pages。

### 国内短视频平台

抖音、小红书和视频号的官方规则页通常没有 RSS。TikHub 等付费 API 虽能补充抖音/小红书，但涉及成本且不等同官方规则源，本轮保持关闭。
